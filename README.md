# amireyzed.com

لندینگ‌پیج شخصی امیر ایزد (AmirEyZed): مسیر کاری سال به سال، روی یک تایم‌لاین. دو زبانه: فارسی در `/` و انگلیسی در `/en/`. ساخته‌شده با [Astro](https://astro.build)، خروجی کاملاً استاتیک.

## ایدهٔ طراحی

- **فضا:** استودیوی امیر در شب. رنگ‌ها از اسکرین‌شات استریم نمونه‌برداری شده‌اند: تاریکی اتاق، نور لیمویی روی دیوار، نئون سفید و سبز Kick.
- **چیدمان:** مثل صفحهٔ تاریخچهٔ nas.co. یک سیم در وسط که با اسکرول سبز روشن می‌شود و سال‌ها و متن‌ها یکی در میان دو طرفش قرار می‌گیرند.
- **لنز شیشه‌ای:** مثل رفرنس توییتر. نزدیک بالا و پایین صفحه، متن‌ها خم و محو می‌شوند و حاشیهٔ رنگی قرمز و آبی می‌گیرند. این دو رنگ از تگ‌های چت کیک در همان اسکرین‌شات آمده‌اند. اسکرول نرم با Lenis انجام می‌شود.
- **تعامل با موس:** نور محیط دنبال نشانگر می‌آید و اسم نئونی به آن واکنش نشان می‌دهد. سال‌ها زیر نشانگر حاشیهٔ رنگی و کمی چرخش می‌گیرند. دکمه‌ها مغناطیسی‌اند و چراغ هر ردیف با هاور روشن می‌شود.
- **دسترس‌پذیری:** با `prefers-reduced-motion` همهٔ حرکت‌ها و لنز خاموش می‌شوند. بدون جاوااسکریپت هم همهٔ محتوا خوانا می‌ماند.

## اجرا در لوکال

```bash
npm install
npm run dev
```

سایت روی `http://localhost:4321` بالا می‌آید. نسخهٔ نهایی با `npm run build` ساخته می‌شود و خروجی در `dist/` است.

## اضافه یا اصلاح کردن یک اتفاق

هر اتفاق یک فایل در `src/content/timeline/` است، مثلاً `2027-something.yaml`:

```yaml
year: 2027
order: 1            # ترتیب داخل همان سال
featured: true      # اختیاری، برای نقطه‌های مهم کریر: عنوان بزرگ‌تر و چراغ پررنگ‌تر
title:
  fa: "عنوان"
  en: "Title"
summary:
  fa: "یکی دو جمله"
  en: "One or two sentences"
why:                # اختیاری، یک جمله که چرا این اتفاق مهم است
  fa: "..."
  en: "..."
highlights:         # اختیاری
  fa: ["عدد یا نکتهٔ کوتاه"]
  en: ["A short number or point"]
guests:             # اختیاری، مهمون‌های مهم یه برنامه یا پادکست؛ هر کارت به قسمتش لینک می‌شه
  - name: { fa: "اسم", en: "Name" }
    about: { fa: "کیه و چرا مهمه", en: "Who they are" }
    url: "https://youtu.be/..."
    stat: { fa: "۱۰۰ هزار بازدید", en: "100K views" }
links:              # اختیاری
  - label: { fa: "ویدیو", en: "Video" }
    url: "https://..."
images:             # اختیاری، حداکثر ۴ عکس کنار همین فایل. اولی بزرگ کنار سال می‌نشیند، بقیه زیر متن
  - src: ./2027-a.jpg
    alt: { fa: "توضیح عکس", en: "Photo description" }
```

بعد از ذخیره، push کن. چند دقیقه بعد سایت آپدیت می‌شود:

```bash
git add . && git commit -m "Add 2027" && git push
```

سال فقط روی اولین اتفاق هر سال بزرگ نمایش داده می‌شود. اتفاق‌های بعدی همان سال، سال را کوچک نشان می‌دهند.

## کجا چی رو عوض کنم

| چی | کجا |
| --- | --- |
| اسم، تگ‌لاین، معرفی، متن «امروز»، آمار کل مسیر، ایمیل، شبکه‌ها | `src/data/site.ts` |
| متن‌های رابط و متا | `src/i18n/ui.ts` |
| رنگ‌ها، فونت‌ها، فاصله‌ها | `src/styles/tokens.css` |
| رفتار اسکرول، لنز و موس | `src/scripts/app.ts` |
| ردیف‌های تایم‌لاین | `src/components/Milestone.astro` |
| آیکون سایت (موز نئونی) | `public/favicon.svg` |
| تصویر اشتراک‌گذاری | `public/og.png` که با `npm run og` ساخته می‌شود |
